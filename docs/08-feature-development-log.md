# 功能开发记录：教学场景扩展

## 记录时间

- 2026-06-17

## 第一轮迭代目标

为教学网页补充三种基础几何体切换能力，并确保现有教学功能继续可用：

- 支持立方体 / 球体 / 圆柱三种模型切换
- 坐标追踪在不同模型下给出合理的默认采样点
- 教学脚本继续沿用 World -> View -> Projection -> MVP 的讲解链路
- 导入 / 导出功能能保存并恢复模型类型与追踪点

## 第一轮新增功能

### 1. 模型类型切换

左侧 World 面板新增“模型类型”下拉框，支持：

- 立方体（box）
- 球体（sphere）
- 圆柱（cylinder）

切换模型时会同步重建：

- 主几何体
- 模型线框
- 当前模型的世界变换显示

该功能的目标不是把项目变成通用模型查看器，而是让同一套矩阵教学逻辑可以作用于不同几何体，便于观察旋转、缩放、投影在不同形体上的视觉差异。

### 2. 坐标追踪推荐点

原先坐标追踪更偏向立方体场景，本次改造后会根据当前模型自动填入推荐点：

- 立方体：前上右角 `(0.5, 0.5, 0.5)`
- 球体：顶部 `(0, 0.75, 0)`
- 圆柱：上边缘 `(0.65, 0.8, 0)`

同时新增“使用推荐点”按钮，用于快速恢复到当前模型更容易观察的采样位置。

### 3. 教学脚本文案兼容

教学脚本原有流程未改变，但描述从“固定立方体”调整为“当前模型”，避免在球体或圆柱模式下出现说明与画面不一致的问题。

### 4. 导入 / 导出兼容

导出 JSON 时新增以下信息：

- `scene.modelType`
- `trackPoint`

重新导入时会恢复：

- 当前模型类型
- 坐标追踪点
- 原有 World / View / Projection 参数

## 交互设计说明

这次新增功能遵循“教学优先”的约束，而不是无限扩展渲染内容：

- 模型类型只保留最基础的三种，避免 UI 复杂化
- 坐标追踪仍以“一个点贯穿 MVP 链路”为核心，不扩展成复杂拾取系统
- 教学脚本继续围绕矩阵本身，而不是围绕具体模型做特化

这样可以保持项目的主线稳定：它依然是矩阵教学工具，而不是 3D 资产浏览器。

## 手工验证建议

建议按以下路径手工验证：

1. 启动项目，切换立方体 / 球体 / 圆柱，确认模型与线框同步变化。
2. 点击“使用推荐点”，确认输入框随当前模型变化。
3. 点击“追踪”，确认模型空间到 NDC 的结果仍正常更新。
4. 运行教学脚本，确认文案与当前模型不冲突。
5. 导出 JSON 后重新导入，确认模型类型与追踪点被正确恢复。

## 第二轮迭代目标

在不破坏原有矩阵教学主线的前提下，把场景表达能力向前推进一层：

- 为每种模型增加多个预置采样点，提升坐标追踪的对比价值
- 增加多物体场景，用同一组 View / Projection 展示多个不同 World
- 增加材质模式切换，用纯色 / 法线 / 棋盘格 / 线框强化观察角度
- 用棋盘格纹理把 UV 与透视缩放的差异带入教学场景

## 第二轮新增功能

### 1. 多个预置采样点

坐标追踪从“每个模型一个推荐点”升级为“每个模型多个预置点”，便于比较不同顶点或代表点在同一套 MVP 下的变化。

当前内置预置点包括：

- 立方体：角点 / 面心 / 边点
- 球体：顶部 / 前极 / 斜向点
- 圆柱：边缘 / 顶心 / 侧面

这样用户不必手动输入一组组坐标，就能更快对比“同一矩阵作用到不同点”时的结果差异。

### 2. 多物体场景布局

World 面板新增“场景布局”选项：

- 单物体
- 三物体

三物体模式下，主模型之外还会出现两个伴随模型。它们与主模型共享同一个 View 和 Projection，但拥有各自的最终 World 结果，用于直观演示：

- 每个物体都可以有自己的世界位置与姿态
- 相机与投影对整张场景统一生效
- 同一组相机参数如何同时影响多个物体

### 3. 材质模式切换

World 面板新增“材质模式”选项：

- 纯色
- 法线
- 棋盘格
- 线框

不同模式的教学价值分别是：

- 纯色：保持最基础的体块观察
- 法线：帮助理解曲面朝向与几何连续性
- 棋盘格：辅助观察 UV 分布与透视缩放
- 线框：强调几何边界和轮廓关系

### 4. 纹理教学的最小闭环

本轮没有单独引入外部贴图资源，而是通过程序生成的棋盘格纹理先建立一个轻量教学闭环。这样做有两个好处：

- 不增加资源文件和加载复杂度
- 可以直接用统一棋盘格观察不同模型上的纹理分布差异

它已经足够支撑下一步围绕 UV、透视和表面展开更系统的说明。

## 第二轮手工验证建议

1. 切换到三物体模式，确认三个模型同时出现在视口中。
2. 调整 World 参数，观察主模型和伴随模型都发生变化，但最终空间位置不同。
3. 切换纯色 / 法线 / 棋盘格 / 线框，确认材质视图切换正常。
4. 在球体和圆柱之间切换棋盘格模式，观察纹理分布和透视观感差异。
5. 在坐标追踪里切换预置点按钮，确认输入框与追踪结果同步变化。

## 当前已完成功能总览

截至本次整理，教学网页已经形成以下几组可直接使用的教学能力：

- 模型类型切换：立方体 / 球体 / 圆柱
- 场景布局切换：单物体 / 三物体
- 材质模式切换：纯色 / 法线 / 棋盘格 / 线框
- 坐标追踪：单点输入 + 每种模型多个预置采样点
- 轴语义增强：
  - 世界轴与局部轴采用统一颜色规则
  - 3D 视图中的 X / Y / Z 轴端标签更清晰
  - 视口图例明确显示 World / Local 对应关系
  - 局部轴更细、更半透明，并标注“随模型移动”
- 教学脚本：继续覆盖 World / View / Projection / MVP 主线
- 导入 / 导出：包含模型类型、布局、材质、追踪点等教学状态

这套功能组合的目标很明确：它仍然是一个矩阵教学工具，但已经具备足够丰富的几何体、布局和视觉语义，能支撑更完整的 3D 管线入门讲解。

## 第三轮迭代目标

在旋转演示过程中，让用户能同时观察到矩阵变化与公式说明，减少“右上看矩阵、右下看不到说明”的视线切换成本：

- 增加矩阵观察模式，支持一键切换“完整模式 / 旋转观察模式”
- 增加按矩阵显隐开关，允许手动隐藏 View/Projection/MVP
- 增强 World 公式提示，按旋转轴给出更具体的平面项解释

## 第三轮新增功能

### 1. 矩阵观察模式

矩阵看板新增“完整模式 / 旋转观察”按钮：

- 完整模式：显示全部矩阵块
- 旋转观察：自动聚焦 World，隐藏 View / Projection / MVP

这样用户在调节旋转时，可以同时观察：

- 右上角 World 矩阵数值变化
- 右下角 World 公式说明与提示

### 2. 单矩阵显隐控制

矩阵区新增 World / View / Projection / MVP 显隐按钮。完整模式下可自由组合显示；旋转观察模式下会锁定显示策略，避免状态混乱。

### 3. 按轴解释的动态提示

World 说明区下方提示升级为按轴解释：

- 只转 Yaw：提示“主要影响 X-Z 平面项”
- 只转 Pitch：提示“主要影响 Y-Z 平面项”
- 只转 Roll：提示“主要影响 X-Y 平面项”
- 多轴旋转：提示“多个平面项同时变化”

并展示当前矩阵中的代表数值，帮助把抽象矩阵项和旋转直觉建立对应关系。
